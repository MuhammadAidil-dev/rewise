## Rewise

This project keeps a memory of past mistakes so they are not repeated.

1. Before any task, read `memory/PROTOCOL.md` and `memory/index.md`, then only
   the entries relevant to the task.
2. When a test/build fails or the user points out a mistake: find the root
   cause, fix it (including leftover code and docs), then follow the record
   gate in the protocol. Do not record trivial or duplicate lessons.
3. Before saying a task is done, run the checklist in `memory/PROTOCOL.md` §7.
